# MediaLab o‘quv materiallari

Ctrl+Shift+A orqali admin panelga kirib mavzu nomlarini va fayllarni yuklang.

- `topics.json`: 20 ta mavzu nomi.
- `topic-01/lecture/`: 1-mavzu ma’ruza fayllari.
- `topic-01/media/`: 1-mavzu video/audio fayllari.
- `topic-01/slides/`: 1-mavzu taqdimotlari.
- `.admin/credential.json`: admin parolining tuz va xeshi. Parolning o‘zi saqlanmaydi.

Kodda yoziladigan to‘rtta resurs: `../TopicPages.cs`.

Materiallar dastur yig‘ilganda natija papkasiga ko‘chiriladi. Mustaqil tarqatishda exe bilan birga `Content` papkasini ham bering.
